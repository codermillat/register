### 1. StudyAbroadGPT
**Repository:** [github.com/codermillat/StudyAbroadGPT](https://github.com/codermillat/StudyAbroadGPT)

A specialized language model based on Mistral-7B, fine-tuned for study abroad guidance.

**Technical Details:**
- 4-bit quantized model for efficient deployment
- LoRA-based fine-tuning for parameter efficiency
- Optimized for T4 GPU with minimal memory footprint
- WandB integration for monitoring
- Structured response generation with markdown formatting

**Performance Metrics:**
- Final Eval Loss: 0.3754 (Excellent)

- Training Steps: 1,191
