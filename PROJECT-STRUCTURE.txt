CLI Commands:
=============

Model Selection:
  node model-selector.js "task description"
  node model-selector.js "task" --max-cost low
  node model-selector.js "task" --provider Anthropic
  node model-selector.js --list reasoning
  node model-selector.js --info claude-sonnet-4.5

Account Rotation:
  node account-rotator.js current
  node account-rotator.js next --model gpt-4o
  node account-rotator.js status
  node account-rotator.js rotate --model o1-preview
  node account-rotator.js rate-limit --account acc-1
  node account-rotator.js reset --account acc-1

Usage Tracking:
  node usage-tracker/usage-tracker.js log --model gpt-4o --tokens 1500
  node usage-tracker/usage-tracker.js view --limit 20
  node usage-tracker/usage-tracker.js stats
  node usage-tracker/usage-tracker.js export csv
  node usage-tracker/usage-tracker.js rate-limit

Smart Spawn:
  node smart-spawn.js "task description"
  node smart-spawn.js "task" --type code
  node smart-spawn.js "task" --max-cost medium
  node smart-spawn.js "task" --provider OpenAI
  node smart-spawn.js "task" --json

Programmatic API:
=================

Model Selection:
  const { selectModel, getModelInfo, listModels } = require('./model-selector');
  
  const choice = selectModel('write Python code', { maxCostTier: 'medium' });
  // Returns: { model, provider, category, confidence, reasoning, modelInfo }

Account Rotation:
  const { getNextAccount, rotateAccount, recordUsage } = require('./account-rotator');
  
  const account = getNextAccount({ requireModel: 'gpt-4o' });
  // Returns: { id, name, tier, models, token }

Usage Tracking:
  const { logUsage, getStats, exportData } = require('./usage-tracker/usage-tracker');
  
  logUsage({ accountId: 'acc-1', model: 'gpt-4o', tokensUsed: 1500 });
  const stats = getStats({ startDate: '2025-01-01' });

Smart Spawn (All-in-One):
  const { smartSpawn, smartSpawnBatch } = require('./smart-spawn');
  
  const result = await smartSpawn({ 
    task: 'analyze algorithm', 
    taskType: 'reasoning' 
  });
  // Returns: { sessionKey, model, account, usageId, duration }

Setup Instructions:
===================

1. Copy Template:
   cp accounts.json.template accounts.json

2. Configure Accounts:
   nano accounts.json
   # Add your API tokens

3. (Optional) Encrypt Tokens:
   openssl rand -hex 32 > .encryption_key
   export ACCOUNT_ENCRYPTION_KEY=$(cat .encryption_key)

4. Test System:
   npm test

5. Start Using:
   node smart-spawn.js "your task description"

6. View Dashboard:
   npm run dashboard
   # Open http://localhost:8080/dashboard.html
