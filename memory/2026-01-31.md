## Major Discovery: GitHub Copilot Pro Account Structure

### Critical Realization
**My entire account rotation system was built on false assumptions.**

**What I thought:**
- Each model has separate quotas (gpt-4o: 500, claude-sonnet: 1000, etc.)
- GitHub API exposes usage data
- Need to track per-model usage separately

**Reality (verified from official GitHub docs):**
1. **GitHub Copilot Pro = 300 premium requests/month TOTAL**
2. **Shared pool across ALL premium models**
3. **Base models unlimited** (GPT-4o, GPT-5 mini, GPT-4.1)
4. **Premium models** consume from shared 300 pool with multipliers:
   - Claude Sonnet 4/4.5: 1× (1 request per prompt)
   - Claude Opus 4.5: 3× (3 requests per prompt)
   - GPT-5, Gemini: 1×
5. **No usage API for individual users** - only org/enterprise endpoints exist
6. **Usage tracked client-side** by OpenClaw (accurate because it counts its own requests)
