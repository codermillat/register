# Research Workflow Examples

How to combine Perplexity Search with other OpenClaw skills for powerful research workflows.

## Workflow 1: Deep Dive Research

**Goal:** Research a topic thoroughly with citations, then create comprehensive analysis.

```bash
# Step 1: Get initial intel with Perplexity
cd skills/perplexity-search
./scripts/perplexity.sh research "AI in EdTech: India vs Global markets" --citations > /tmp/edtech-intel.txt

# Step 2: Deep analysis with Deep Research
cd ../deep-research
./scripts/research.sh "Analyze EdTech market trends" --context /tmp/edtech-intel.txt --output ~/research-report.md

# Step 3: Save to memory
cd ../memory-manager
./scripts/save.sh --file ~/research-report.md --tag edtech --tag market-research
```

**Result:** Comprehensive, cited research report saved to long-term memory.

## Workflow 3: Fact-Checking Pipeline

**Goal:** Verify claims before using in content.

```bash
# List of claims to verify
claims=(
    "Python is the most popular programming language in 2026"
    "GitHub Copilot increased developer productivity by 50%"
    "AI can replace teachers in schools"
)

# Check each claim
for claim in "${claims[@]}"; do
    echo "Checking: $claim"
    ./scripts/perplexity.sh fact "$claim" >> fact-check-report.txt
    echo "---" >> fact-check-report.txt
done

# Save verified facts
cd ../memory-manager
./scripts/save.sh --file fact-check-report.txt --tag fact-check
```

**Result:** Verified fact sheet with sources.

## Workflow 4: Content Research + YouTube Discovery

**Goal:** Research a topic, then find relevant video content.

```bash
# Research the topic
./scripts/perplexity.sh research "Best practices for teaching coding to beginners"

# Based on findings, search for video tutorials
cd ../youtube-transcript
./scripts/search.sh "coding tutorials for beginners 2026"

# Get transcript of top result
./scripts/transcript.sh "https://youtube.com/watch?v=..."

# Combine insights
echo "## Written Research" > content-brief.md
./scripts/perplexity.sh research "coding pedagogy" >> content-brief.md
echo "\n## Video Content Analysis" >> content-brief.md
cd ../youtube-transcript
./scripts/transcript.sh "VIDEO_URL" >> content-brief.md
```

**Result:** Multi-source content brief combining research and video analysis.

## Workflow 5: Market Monitoring

**Goal:** Daily market intelligence gathering.

```bash
#!/bin/bash
# daily-intel.sh - Run this as a cron job

DATE=$(date +%Y-%m-%d)
REPORT="~/market-intel-$DATE.md"

echo "# Market Intelligence - $DATE" > $REPORT
echo "" >> $REPORT

# EdTech news
echo "## EdTech News" >> $REPORT
cd skills/perplexity-search
./scripts/perplexity.sh search "EdTech news today" --citations >> $REPORT
echo "" >> $REPORT

# Competitor updates
echo "## Competitor Updates" >> $REPORT
./scripts/perplexity.sh search "Byju's Unacademy news updates" >> $REPORT
echo "" >> $REPORT

# Tech trends
echo "## Technology Trends" >> $REPORT
./scripts/perplexity.sh search "AI education tools releases" >> $REPORT
echo "" >> $REPORT

# Stock watch (if applicable)
echo "## Market Performance" >> $REPORT
cd ../yahoo-finance
./scripts/quote.sh CHGG >> $REPORT  # Chegg
./scripts/quote.sh DUOL >> $REPORT  # Duolingo

# Save to memory
cd ../memory-manager
./scripts/save.sh --file $REPORT --tag daily-intel --tag market
```

**Result:** Automated daily intelligence report.

## Workflow 7: Multi-Source Synthesis

**Goal:** Combine Perplexity (web), Yahoo Finance (market data), and YouTube (video) for complete picture.

```bash
COMPANY="OpenAI"

# Web research
cd skills/perplexity-search
./scripts/perplexity.sh research "$COMPANY business strategy 2026" > /tmp/web.txt

# Stock data (if public)
cd ../yahoo-finance
./scripts/quote.sh OPENAI > /tmp/finance.txt 2>/dev/null || echo "Not public" > /tmp/finance.txt

# Find CEO interviews/talks
cd ../youtube-transcript
./scripts/search.sh "$COMPANY CEO interview 2026" | head -1 | xargs ./scripts/transcript.sh > /tmp/video.txt

# Combine
{
    echo "# $COMPANY Intelligence Report"
    echo ""
    echo "## Web Research"
    cat /tmp/web.txt
    echo ""
    echo "## Financial Data"
    cat /tmp/finance.txt
    echo ""
    echo "## Leadership Insights (Video)"
    cat /tmp/video.txt
} > "$COMPANY-report.md"

# Save
cd ../memory-manager
./scripts/save.sh --file "$COMPANY-report.md" --tag company-intel --tag "$COMPANY"
```

**Result:** Multi-dimensional company profile.

## Workflow 8: Perplexity → Deep Research → n8n Automation

**Goal:** Research → Analysis → Automated actions.

```bash
# Get market intel
cd skills/perplexity-search
result=$(./scripts/perplexity.sh research "EdTech funding trends Q1 2026" --json)

# Analyze with Deep Research
cd ../deep-research
analysis=$(./scripts/research.sh "Analyze funding trends for strategic opportunities" --context "$result")

# Trigger n8n workflow with findings
cd ../n8n
./scripts/trigger.sh --webhook "market-analysis" --data "$analysis"

# n8n can then:
# - Post to Slack
# - Update CRM
# - Send email alerts
# - Update dashboards
```

**Result:** Automated intelligence pipeline.

## Best Practices

### 1. Chain Skills Sequentially
```bash
result=$(skill1) && skill2 "$result" && skill3
```

### 2. Use Temp Files for Large Data
```bash
./scripts/perplexity.sh research "topic" > /tmp/data.txt
other-skill --input /tmp/data.txt
```

### 3. Save Important Research
```bash
# Always save to memory
result=$(./scripts/perplexity.sh research "topic")
echo "$result" | ../memory-manager/scripts/save.sh --tag research
```

### 4. Use JSON for Programmatic Workflows
```bash
result=$(./scripts/perplexity.sh search "query" --json)
answer=$(echo "$result" | jq -r '.answer')
citations=$(echo "$result" | jq -r '.citations[]')
```

### 5. Automate Repetitive Research
```bash
# Create wrapper scripts for common patterns
cat > ~/bin/daily-research.sh <<'EOF'
#!/bin/bash
cd ~/.openclaw/workspace/skills/perplexity-search
./scripts/perplexity.sh research "$1" | tee ~/research/$(date +%Y-%m-%d)-$1.md
EOF
chmod +x ~/bin/daily-research.sh
```
