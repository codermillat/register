### Request Flow

```
┌─────────────────────────────────────────────────┐
│         User Request to OpenClaw                │
└─────────────────┬───────────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────────┐
│    OpenClaw Copilot Integration                 │
│    • Intercepts request                         │
│    • Extracts task description                  │
└─────────────────┬───────────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────────┐
│    Intelligent Rotator                          │
│    • Analyzes task complexity                   │
│    • Scores all account+model combinations      │
│    • Selects best option                        │
└─────────────────┬───────────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────────┐
│    Copilot Token Store                          │
│    • Retrieves encrypted token                  │
│    • Decrypts for use                           │
└─────────────────┬───────────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────────┐
│    OpenClaw Credential Update                   │
│    • Updates github-copilot.token.json          │
│    • Updates auth profiles                      │
└─────────────────┬───────────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────────┐
│    GitHub Copilot API Request                   │
│    • Makes API call with selected token         │
│    • Returns response                           │
└─────────────────┬───────────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────────┐
│    Usage Recording                              │
│    • Increments usage counter                   │
│    • Logs rotation decision                     │
│    • Updates statistics                         │
└─────────────────────────────────────────────────┘
```
