## 💡 POWER TIPS

### Combine Skills
Don't use skills in isolation:
- **Research** → **YouTube** → **Council** → **Memory**
- **Proactive** → **Deep Research** → **Self Reflection**
- **Yahoo Finance** → **Research** → **Council**

### Use Proactive Agent
This is your secret weapon:
- Asks "what would help?" instead of waiting
- Suggests ideas you didn't think of
- Gets better over time

### Build Council Perspectives
Add custom experts to `agents/` folder:
```bash
echo "# SecurityExpert\n\nAnalyze security..." > agents/SecurityExpert.md
echo "# Educator\n\nTeaching perspective..." > agents/Educator.md
```

### Let Memory Compound
Save important contexts:
```
"Save this conversation"
"Save these insights about [topic]"
```
Search later:
```
"Search memories for 'student engagement'"
```
