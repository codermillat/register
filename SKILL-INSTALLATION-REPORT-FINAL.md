### Chain Skills Together
Single skills are useful. Combined skills are powerful:
- **Research → YouTube → Council → Memory**
- **Proactive → Deep Research → Self Reflection**
- **Yahoo Finance → Research → Council**

### Use Proactive Agent Daily
Ask every morning:
```
"What should I be thinking about?"
"Any suggestions for today?"
```

### Build Council Expertise
Add custom experts matching your needs:
```bash
# EdTech educator perspective
echo "# Educator\n\nExpert educator analyzing..." > agents/Educator.md

# Student perspective
echo "# Student\n\nStudent perspective on..." > agents/Student.md

# Accessibility expert
echo "# A11yExpert\n\nAccessibility analysis..." > agents/A11yExpert.md
```

### Compound Memory
Don't just save - build on:
```
"Save this research"
"What did I learn about [topic] before?"
"Combine today's insights with previous research"
```
